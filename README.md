# 🌱 Observatorio de Datos para la Economía del Cuidado - CDMX

Proyecto integrador de la Licenciatura en Ciencias de Datos para Negocios (UNRC, 2026-2).

## 📋 Descripción

Este proyecto construye un **Observatorio de Datos** sobre la economía del cuidado en la Ciudad de México, con el objetivo de visibilizar cómo las responsabilidades de cuidado impactan la inserción laboral de la población, especialmente de las mujeres...
